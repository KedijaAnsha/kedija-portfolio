> A modern, responsive personal portfolio website and ATS-compliant single-page Curriculum Vitae (CV) for **Kedija Ansha**, a fourth-year Software Engineering undergraduate student at **Wachemo University, Ethiopia**.

---

## 🌟 Key Highlights

* **Modern Dark Aesthetic**: Atmospheric landscape hero backdrop, centered circular profile headshot with an accent ring, dynamic typing tagline, and minimalist typography.
* **Dual Experience**:
  * **Interactive Portfolio (`index.html`)**: Rich showcase with project case studies, skill visualizations, multilingual proficiencies, timeline milestones, and contact integrations.
  * **ATS-Compliant Single-Page CV (`cv.html`)**: Tailored two-column format formatted strictly to print or export as an **A4 PDF** without overflowing.
* **Semantic & Lightweight**: Pure HTML5, modern CSS3 (Flexbox & CSS Grid), and vanilla JavaScript with zero heavy dependencies or frameworks.
* **Mobile First & Fully Responsive**: Seamlessly adapts across desktops, laptops, tablets, and smartphones.
